## Aim of the experiment

## Theory
To write, compile, and run a Java program, the Java Development Kit (JDK) must be properly configured. The installation setup involves configuring environment variables:
1. **JAVA_HOME**: Points to the JDK installation directory (e.g., `C:\Program Files\Java\jdk-17` on Windows or `/usr/lib/jvm/java-17-openjdk` on Linux).
2. **PATH**: Appended with the `bin` subdirectory of the JDK installation (e.g., `%JAVA_HOME%\bin` or `$JAVA_HOME/bin`) to allow executable tools like `javac` (the compiler) and `java` (the execution launcher) to run from any terminal directory.

### Java Primitive Data Types
Java is a strongly typed programming language, meaning every variable must be declared with a predefined data type. The primary numeric and simple primitive types include:
* `int`: 4-byte integer values for whole numbers without decimals (e.g., `12`).
* `float`: 4-byte single-precision floating-point numbers (e.g., `4.0f`).
* `double`: 8-byte double-precision floating-point numbers (e.g., `2.5`).
* `char`: 2-byte Unicode character enclosed in single quotes (e.g., `'A'`).
* `boolean`: represents truth values: `true` or `false`.

### Operator Precedence & Expressions
Arithmetic operations in Java follow strict operator precedence (similar to BODMAS/PEMDAS rules):
1. Parentheses `()` have the highest evaluation precedence.
2. Multiplication `*`, Division `/`, and Modulo `%` are evaluated next, from left to right.
3. Addition `+` and Subtraction `-` are evaluated last, from left to right.

**Type Cast Promotion:** In mixed-type expressions, automatic widening occurs (e.g., operating an `int` with a `double` promotes the `int` to a `double`). Manual explicit casting, such as `(float)`, can be used to prevent integer truncation (like fractional loss in integer-only division).


## Code(if needed)
```java
public class ExpressionEvaluator {
    public static void main(String[] args) {
        // Declaring primitive data types
        int a = 12;
        int b = 5;
        double c = 2.5;
        float d = 4.0f;
        
        // Evaluating expressions showcasing operator precedence
        double result1 = a + b * c;          // Precedence: Multiplication before addition
        double result2 = (a + b) * c;        // Precedence: Parentheses override addition
        float result3 = (a / b) + d;         // Integer division occurs (12 / 5 = 2) then adds 4.0f
        float result4 = ((float) a / b) + d; // Explicit float casting occurs (12.0f / 5 = 2.4f) then adds 4.0f
        
        // Printing the values and evaluation results
        System.out.println("--- Primitive Data Types & Operator Precedence ---");
        System.out.println("Variable values: a = " + a + ", b = " + b + ", c = " + c + ", d = " + d);
        System.out.println("Expression 1 (a + b * c)       = " + result1);
        System.out.println("Expression 2 ((a + b) * c)     = " + result2);
        System.out.println("Expression 3 (a / b + d)       = " + result3 + " (Integer division)");
        System.out.println("Expression 4 ((float)a / b + d)= " + result4 + " (Type cast division)");
    }
}
```
