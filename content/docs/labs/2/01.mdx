## Aim of the experiment
> To architect and test fundamental client-server execution scripts ensuring active communication loops between local network nodes using JavaScript and Node.js.


## Theory
Client-server architecture is a distributed application structure that partitions workloads between service providers (servers) and service requesters (clients).
* **Server Node (Node.js):** Uses Node.js built-in modules (such as `http`) to create an asynchronous, event-driven server listening on a designated network port (e.g., port 3000). It processes incoming request streams, extracts request metadata, and dispatches structured responses.
* **Client Node (JavaScript/Node.js):** Initiates asynchronous HTTP requests to the server node using JavaScript APIs such as `fetch()` or Node.js native `http.request()` modules.
* **Event-Driven Execution Loop:** Node.js operates on a single-threaded non-blocking I/O event loop, allowing the server node to handle multiple client socket connections concurrently without blocking thread execution.


## Code
```js title="server.js"
// Node.js HTTP Server Node handling incoming client requests
const http = require('http');

const PORT = 3000;
const HOST = '127.0.0.1';

const server = http.createServer((req, res) => {
    // Extract request details
    const clientIP = req.socket.remoteAddress;
    const method = req.method;
    const url = req.url;
    const timestamp = new Date().toISOString();

    console.log(`[${timestamp}] Received ${method} request for ${url} from ${clientIP}`);

    // Set HTTP response headers
    res.writeHead(200, { 'Content-Type': 'application/json' });

    // Construct response payload
    const responseData = {
        status: 'SUCCESS',
        message: 'Active communication loop verified with Server Node',
        timestamp: timestamp,
        clientMetadata: {
            ip: clientIP,
            method: method,
            endpoint: url,
            userAgent: req.headers['user-agent']
        }
    };

    // Send JSON response payload
    res.end(JSON.stringify(responseData, null, 2));
});

server.listen(PORT, HOST, () => {
    console.log(`Server Node running at http://${HOST}:${PORT}/`);
});
```

```js title="client.js"
// Node.js Client Node initiating an asynchronous request to the server
const http = require('http');

const options = {
    hostname: '127.0.0.1',
    port: 3000,
    path: '/api/status',
    method: 'GET',
    headers: {
        'User-Agent': 'NodeJS-Client-Node/1.0'
    }
};

console.log(`Client Node: Initiating HTTP GET request to http://${options.hostname}:${options.port}${options.path}...`);

const req = http.request(options, (res) => {
    let rawData = '';

    console.log(`Client Node: Server Response Received | Status Code: ${res.statusCode}`);

    res.on('data', (chunk) => {
        rawData += chunk;
    });

    res.on('end', () => {
        try {
            const parsedData = JSON.parse(rawData);
            console.log('Client Node: Decoded JSON Response Payload:');
            console.log(JSON.stringify(parsedData, null, 2));
        } catch (e) {
            console.error(`Error parsing response: ${e.message}`);
        }
    });
});

req.on('error', (e) => {
    console.error(`Client Node Request Error: ${e.message}`);
});

req.end();
```
