## Aim of the experiment
> To implement advanced layout design system rules and responsive styling architectures utilizing Cascading Style Sheets (CSS) served via a Node.js web server.


## Theory
Cascading Style Sheets (CSS) define the presentation, layout, and visual formatting of HTML elements within web applications. Modern CSS layout systems enable responsive, flexible, and adaptive user interfaces across various screen viewports. Node.js serves as the server environment delivering HTML and CSS assets. Key concepts include:
* **CSS Box Model:** Defines element dimensions including content, padding, border, and margin areas. Applying `box-sizing: border-box` includes padding and borders in total width and height calculations.
* **Flexbox Layout:** A one-dimensional layout system designed for distributing space along a single axis (row or column), utilizing properties such as `display: flex`, `justify-content`, and `align-items`.
* **CSS Grid Layout:** A two-dimensional grid system providing column and row placement control, using properties like `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))`.
* **Media Queries & Node.js Asset Serving:** Utilizing CSS `@media` rules to adjust styles dynamically according to screen dimensions, while Node.js handles static file requests using the core `http` and `fs` modules.

```javascript title="server.js"
// Node.js HTTP server for hosting static HTML/CSS web layout assets
const http = require('http');
const fs = require('fs');
const path = require('path');

const PORT = 3000;
const HOST = '127.0.0.1';

const server = http.createServer((req, res) => {
    let filePath = path.join(__dirname, 'public', req.url === '/' ? 'index.html' : req.url);

    fs.readFile(filePath, (err, content) => {
        if (err) {
            res.writeHead(404, { 'Content-Type': 'text/plain' });
            res.end('404 Not Found');
        } else {
            res.writeHead(200, { 'Content-Type': 'text/html' });
            res.end(content, 'utf-8');
        }
    });
});

server.listen(PORT, HOST, () => {
    console.log(`Node.js Server hosting CSS interface at http://${HOST}:${PORT}/`);
});
```
